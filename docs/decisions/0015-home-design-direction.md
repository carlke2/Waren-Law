# 0015: Home design follows the owner's reference (dark teal, honeycomb)

**Date:** 4 November 2026
**Status:** Replaced by 0016

## Decision
1. The owner's reference (`docs/design/reference/home-reference.png`) sets the look: dark teal palette, cinematic city hero, light/bold uppercase headline, five-hexagon honeycomb, centred firm statement, four-column footer.
2. `docs/design/DESIGN-SPEC.md` v2 specifies it with WAREN content. WAREN's gold is used for the logo only.
3. **Home, header and footer only** are built now. Other pages wait for Home approval.
4. The hero uses an image now; the component accepts a background video later (Settings), with the image kept for mobile and reduced motion.
5. The frontend is reset first (ground rules, decision 0014).

## Why
The owner chose a concrete visual; matching it exactly with WAREN's content removes guesswork.
