# 0029 — Home “What we handle” list

Decision: Replace the three peach practice cards on the homepage with an ivory two-column numbered list of all eight practice areas, matching the intro section’s fonts and ivory/gold palette.

Why: The approved home redesign continues the editorial intro look into the services band; cards and a pill CTA did not match that language.

Consequences: `HOME_SERVICE_COUNT` is 8. The section uses shared intro colours plus a few expertise-only tokens (description grey, item rule, hover wash, curve). Descriptions come from each area’s `cardSummary`.
